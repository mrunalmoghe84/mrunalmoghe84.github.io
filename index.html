AI & LLM Tools
N° 01 · 2026

RAG Document Chatbot

Independent Project · Retrieval-Augmented Generation

A deployed full-stack RAG application that lets users upload PDFs and query them conversationally. Frontend is a static site on GitHub Pages; backend runs on Render with Node.js/Express, decodes base64 document blocks server-side, extracts text via pdf-parse, and injects it into prompts against Groq's llama-3.3-70b-versatile model — with a 30k character cap per file and a keep-alive ping to survive free-tier spin-down.

A working blueprint for secure client-side RAG: API keys stay off the browser, cost stays near zero, and the UX still feels instant.

AI Content Automation Engine

Independent Project · Instagram & X · Hetzner VPS

A single-file web app that learns from engagement patterns and generates platform-optimised content for Instagram and X with minimal manual intervention. Four tabs: engagement insights dashboard, post training data, AI content auto-generation via Anthropic API, and settings. A closed-loop content system that treats social publishing as a product surface — not a chore — with engagement data feeding directly back into generation.

User Story Analyzer

Independent Project · Full-Stack Web App

A web tool for product teams that ingests a Business Context and a User Story, then auto-generates a gap analysis, a UI prototype mockup, and structured feature documentation. Frontend hosted on GitHub Pages; Node.js/Express backend acts as a secure proxy to the Anthropic Claude API, with CORS restricted to the Pages origin and requests validated via an app-secret header.
